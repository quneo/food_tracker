# Food Tracker

Self-hosted дневник питания, веса и прогресса тела с AI-ассистентом на Codex CLI.

**Telegram-бот** — главный способ что-то записать и поговорить с ассистентом:
- прислать фото еды или описать ее словами;
- исправить запись или задать вопрос;
- записать вес, замеры, фото прогресса;
- попросить напоминание.

**Веб-приложение** (mobile-first, есть Mini App в Telegram) — для просмотра и правки
дневника, графиков, отчетов, альбома прогресса, профиля и AI-памяти.

## Возможности

- **Фото или текст → запись с КБЖУ.**
  - Состав блюда, вес каждого компонента, калории и БЖУ, диапазон и уверенность оценки,
    допущения.
  - Запись приходит черновиком с кнопками «Сохранить / Исправить / тип приема пищи».
  - Граммовки, которые AI оценил, никогда не показываются как измеренные: `~150 г`.
- **Исправления словами.** «Риса было 200 г», «удали вчерашний ужин», «это был перекус».
  Изменения сохраненных записей ждут подтверждения.
- **Вес, замеры, фото тела** — обычными сообщениями. Фото с подписью «прогресс» и в режиме
  `/progress` в AI не отправляются.
- **Разговор с ассистентом**, который знает профиль, цели, историю питания и веса и
  долговременную память (ее можно смотреть и править).
- **Напоминания** «записать еду», «взвеситься», «фото прогресса» и свои. Они идут по
  часовому поясу человека и пропускаются, если уже сделано.
- **На сайте:**
  - главная с итогами дня;
  - дневник с фото и ручной правкой;
  - аналитика по дням, неделям и месяцам с честной обработкой незаполненных дней;
  - сводные отчеты;
  - альбом прогресса со сравнением двух фото (рядом или ползунком);
  - профиль, напоминания, AI-память, администрирование.
- **Несколько пользователей с полной изоляцией данных.**
  - Вход через Telegram: подтверждение в чате с ботом, Login Widget или Mini App.
  - Закрытый режим по приглашениям.
  - Администратор не видит чужих фото и диалогов.
  - Удаление аккаунта удаляет и данные, и файлы.

## Архитектура

```
Telegram ──▶ bot (aiogram 3) ──▶ backend (FastAPI) ──▶ SQLite (WAL) / MinIO (фото)
                ▲   outbox          │  фоновые AI-задачи
                └───────────────────┤
browser ──▶ frontend (React, nginx) ┘  ssh (forced command) ──▶ VPS: runner ──▶ codex exec
```

| Модуль | Где | Что делает |
|---|---|---|
| `api` | `backend/app/api` | REST API, авторизация (сессии в БД, Telegram-подписи), админка |
| `ai` | `backend/app/ai` | SSH runner, задачи, промт, контекст, память, проверка действий |
| `nutrition` | `backend/app/nutrition` | приемы пищи, продукты, КБЖУ, нормы (Mifflin-St Jeor) |
| `progress` | `backend/app/progress` | вес, замеры, фото прогресса |
| `media` | `backend/app/media` | MinIO: оригиналы, превью WebP, удаление файлов |
| `reminders` | `backend/app/reminders` | расписание в часовом поясе, доставка через outbox |
| `analytics` | `backend/app/analytics` | дни, статусы заполненности, отчеты |
| `chat` | `backend/app/chat` | сообщения бота, кнопки, outbox |
| `bot` | `bot/` | Telegram: сообщения, альбомы, кнопки, доставка outbox |
| `runner` | `runner/` | ограниченный запуск Codex на VPS |
| `frontend` | `frontend/` | React + TypeScript + Vite + Tailwind + shadcn/ui + Recharts |

Подробности:
- [docs/ai.md](docs/ai.md) — устройство ассистента, промт, память, источники;
- [docs/deploy.md](docs/deploy.md) — развертывание, домен, бэкапы;
- [docs/vps-codex.md](docs/vps-codex.md) — Codex на VPS.

## Запуск

```sh
cp .env.example .env     # заполнить токен бота, секреты, ADMIN_TELEGRAM_IDS
docker compose up -d --build                     # или с --profile tg-proxy
```

Сайт открывается на `http://127.0.0.1:8090`, порт задается `FRONTEND_PORT`. Без Codex
(`AI_RUNNER=off`) все работает, кроме разбора еды и диалога.

## Разработка и тесты

```sh
python -m venv .venv
.venv/Scripts/python -m pip install -e "backend[test]" -e "bot[test]"   # Linux: .venv/bin/...
cd backend && ../.venv/Scripts/python -m pytest      # API, изоляция, AI-цепочка с фейковым Codex
cd bot && ../.venv/Scripts/python -m pytest          # отрисовка, доставка, ошибки API
python -m pytest runner/test_runner.py               # runner с фейковым codex (только Linux)
cd frontend && corepack pnpm install && corepack pnpm dev
```

У backend и bot общее имя пакета `app`. Поэтому ставьте их только в editable-режиме (`-e`) и
запускайте тесты из папки сервиса через `python -m pytest`.
